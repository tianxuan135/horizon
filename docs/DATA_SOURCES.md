# 数据源与合规矩阵 · Data Sources

> 本文是 Horizon（极目楚天）的数据来源登记簿，也是新增数据源的评审依据。
> 一句话原则：**能拿到什么就标注什么，拿不到就说拿不到，绝不把代理指标伪装成真实数据。**

---

## 0. 六条硬性合规原则

1. **合法性优先于完整性。** 无合法免费接口的数据品类，宁可用代理指标，也不绕过付费墙、登录态、验证码或 robots 限制。
2. **来源必须可追溯。** 每个接口响应都带 `source` 与 `asOf`；走兜底或代理时必须同时出现在 `warnings[]` 中。
3. **合成不等于真实。** 内置 `synthetic` 数据是确定性生成的代理数据，仅用于无网络/上游全挂时的功能可演示性，界面上必须显式标注。
4. **不自建再分发。** 本项目是自托管个人研究工具，不提供数据再分发服务；使用者自行承担所在司法辖区的合规责任。
5. **凭据不入库。** 任何 token / key 只经环境变量注入，`.env` 与 `.env.example` 中不出现真实值。
6. **不诱导交易。** 数据与指标只用于研究展示，不构成投资建议，也不提供荐股、带单、自动交易能力。

## 1. 当前已接入 / 计划接入的数据源

`是否免费` 一列指「无需付费即可程序化访问」，不代表允许商业使用或再分发。

| 来源 | 类型 | 是否免费 | 授权与条款风险 | 用途 | 降级替代 |
| --- | --- | --- | --- | --- | --- |
| **Yahoo Finance 公开 JSON 接口**（`query1.finance.yahoo.com`） | 美股+A股行情、日线、标的搜索 | 免费，无需 key | 非官方公开接口，无 SLA、无稳定性承诺；服务条款限制商业使用与批量再分发；可能随时变更字段或限流 | 美股行情**主源**；A 股兜底源 | AKShare → `synthetic` |
| **AKShare**（开源库，MIT，封装多个公开站点） | A 股行情、行业板块、指数、基本面片段 | 免费 | 库本身 MIT，但**数据不属于该库**；上游站点各自有条款与频率限制；上游改版即失效 | A 股行情**主源**；美股兜底源 | Yahoo → `synthetic` |
| **Tushare Pro**（可选） | A 股结构化数据（财务、板块、资金流） | 部分免费（积分制），完整数据需付费 | 需个人 token；禁止转售/再分发；免费额度限个人研究；账户被封会导致取数中断 | 可选增强：更规整的 A 股财务与资金流 | AKShare → `synthetic`；**默认不启用** |
| **Finnhub**（可选） | 美股报价、公司资料、新闻 | 免费额度 + 商业套餐 | 免费层限个人/非商业用途，需署名；有速率限制；商业使用需购买授权 | 可选增强：公司资料与新闻 | Yahoo → `synthetic`；**默认不启用** |
| **内置 `synthetic` 合成引擎**（`api/app/providers/synthetic.py`） | 确定性生成的代理行情与指标 | 免费（本地计算） | 无版权风险；但**不是真实数据**，禁止在界面/导出物中冒充真实行情 | 无网络、上游全挂时的兜底，保证功能可演示 | 无（链路终点） |
| **交易所 / 监管机构公开信息**（公告、规则文本、指数编制说明） | 说明性文本 | 免费 | 需遵守署名要求；不得暗示获得官方认可或背书 | 指标口径说明、帮助文档 | 无（静态文本） |

> 上表中 Tushare / Finnhub 的开关语义是：未配置 token 时对应 provider 直接跳过，链路自动落到下一级，不会报错。这一点由 `api/app/providers/base.py` 的 `_chain()` 与 `provider_status()` 保证。

## 2. 无合法免费接口的品类，以及本项目的替代方案

以下四类数据在公开互联网上**没有可合法、稳定、免费程序化获取的接口**。商业供应商（如暗池成交、13F 清洗库、社媒情感 API、搜索热度 API）均需付费授权，且条款普遍禁止再分发。

本项目**不接入、不爬取、不模拟**这些原始数据，而是改用**公开代理指标（proxy indicators）**，并在 API 与界面上显式标注。

| 品类 | 为什么拿不到真实数据 | 本项目使用的代理指标 | 代理的直观含义 | 标注方式 |
| --- | --- | --- | --- | --- |
| **暗池成交 / 机构大宗** | 个股级暗池数据由商业数据商提供；监管公开数据只有延迟汇总，无个股级实时明细，且不可再分发 | 由公开日线的**成交额分布**推演的「大单集中度」+「成交量相对 20 日均值偏离度」 | 成交是否集中在少数大额交易上，近似反映非公开撮合活跃度 | `source: "synthetic"` + `warnings: ["proxy: darkpool 为公开量价推演的代理指标，非暗池真实成交"]` |
| **13F 机构持仓明细** | SEC EDGAR 原文免费但**滞后约 45 天、仅季度、需自行清洗**；聚合级持仓库为商业产品 | **ETF 份额变动** + 板块层面的资金流方向（由公开价格与成交额推演） | 机构/被动资金的中期配置方向，而非单只标的的机构持仓 | `source: "synthetic"` + `warnings: ["proxy: 13f 为 ETF 份额与板块资金流代理，非 13F 明细"]` |
| **Reddit / 雪球 等社媒情感** | 平台条款禁止未经许可的抓取与再分发；无官方免费 API；早期免费接口已关停 | **换手率分位 + 振幅分位 + 成交量异动**（关注度代理） | 讨论热度上升通常伴随成交与波动放大，用交易侧指标近似「关注度」 | `source: "synthetic"` + `warnings: ["proxy: social 为成交/波动推演的关注度代理，未使用任何社媒原文"]` |
| **Google Trends 搜索热度** | 无官方公开 API；非官方抓取违反其条款、易被封禁且不稳定 | 同上的**成交量分位 + 振幅分位**，以及公告/新闻标题词频（若数据源已授权） | 用市场自身行为近似「公众关注度」 | `source: "synthetic"` + `warnings: ["proxy: trends 为量价推演的关注度代理，未调用 Trends"]` |

代理指标的**共同局限**，必须在使用页面与文档中标明：

- 它们度量的是「市场行为的侧面」，不是原始数据本身；
- 在极端行情或流动性枯竭时可能失真；
- 不可用于推断具体机构行为或个体情绪。

> 因此，拥挤度模型中的 `social` 分量（权重 0.15）在缺少真实社媒数据时，计算的是**关注度代理**，不是情感极性。API 契约要求此时返回 `source: "synthetic"` 并在 `warnings[]` 中给出 `proxy: social` 说明。

## 3. `source` 字段取值规范

`docs/API_CONTRACT.md` 规定所有响应携带 `source` 与 `asOf`。取值语义如下：

| `source` 取值 | 含义 | UI 展示要求 |
| --- | --- | --- |
| `yahoo` | 来自 Yahoo Finance 公开接口 | 可标注「Yahoo 公开数据」，同时标注延迟/非官方属性 |
| `akshare` | 来自 AKShare 封装的公开站点 | 可标注「AKShare 聚合公开数据」 |
| `synthetic` | 内置合成数据，或由公开量价推演的**代理指标** | **必须**显示「合成/代理数据」角标；若有 `warnings[]` 需可展开查看原因 |
| （预留）`proxy` | 未来若在契约中独立区分代理指标，可新增该取值 | 需先用 PR 更新 `API_CONTRACT.md` 与前端角标 |

当前实现只区分上述三种来源；代理指标统一以 `source: "synthetic"` + `warnings[]` 前缀 `proxy: <品类>` 呈现。任何新增取值都必须同步更新接口契约、前端角标与本文档。

## 4. 使用者（自托管者）需要自行确认的事项

- **个人研究 vs 商业用途**：Yahoo 等公开接口的服务条款通常限制商业使用。若将本工具用于商业场景，请自行获得相应授权或替换数据源。
- **频率与礼貌**：请保持 `api/app/cache.py` 中的 TTL 配置，不要为了「更实时」把报价 TTL 调到 0；对上游的高频轮询既违反条款也容易被封。
- **数据留存**：本项目默认只在本地 SQLite / 自建 Postgres 中留存必要的历史序列，不对外提供数据下载服务。请勿将第三方原始数据打包再分发。
- **署名义务**：若启用了需要署名的数据源（如 Finnhub 免费层），请在部署站点上按对方要求标注来源。
- **司法辖区**：不同地区对金融数据使用与展示有不同规定，请以所在地法规为准。

## 5. 新增数据源的评审流程

新增任何数据源前，PR 必须包含：

1. 来源名称、官方文档链接、许可/服务条款链接；
2. 是否允许程序化访问、是否允许缓存、是否允许再分发的明确判断；
3. `docs/DATA_SOURCES.md` 本表新增一行；
4. `api/app/providers/base.py` 中 `provider_status()` 的 `license` 文案更新；
5. 失败降级路径说明（必须能退回已有源或 `synthetic`）；
6. 频率限制与 TTL 取值说明。

评审要点：**没有合法免费来源的品类不得因「数据好看」而接入真实抓取；只能用代理指标并明确标注。**
