# Horizon 极目楚天 v0.1.0

面向开源社区与个人开发者的**美股 / A 股双市场研究分析工具**首个可用版本。
Apple 风格界面，六大分析模块，全部计算在服务端完成，开箱可用、可自托管。

> 本工具所有数据及分析结果仅供学习研究参考，不构成任何投资建议。

## 本次发布包含什么

| 模块 | 能力 |
| --- | --- |
| 市场拥挤度 | 13 个固定行业 × 7 个周期；五维加权（资金 33% / 补仓 22% / 焦虑 18% / 社交 15% / 传播 12%）；综合主图叠加基准指数；五维结构雷达图；365 天历史曲线 |
| 风格轮动 | 大盘 vs 小盘、科技 vs 消费两组对比；−100 ~ +100 轮动分数；读数面板含指针刻度、当前偏向与 Z 值 |
| 估值分析 | 消费 / 周期 / 科技三类；基本面、护城河、可替代性、资本开支四维评分；全市场搜索 + 自选股管理 |
| 因子策略 | 因子回测（净值 / 回撤 / 夏普 / 年化 / Alpha / Beta / 胜率）+ 因子挖取（Rank-IC / ICIR / t 值） |
| 期权策略 | 策略回测 + 计算器：9 种预设与自定义腿，自动算最大收益、最大风险、净权利金、盈亏平衡 |
| 账号与设置 | 邮箱注册登录（默认关闭，可配 SMTP 开启验证码）、市场切换、数据状态、问题反馈、免责声明 |

## 技术栈

Next.js 15 + TailwindCSS + Framer Motion + ECharts ｜ FastAPI + SQLAlchemy + APScheduler（可选 Celery）｜ PostgreSQL / SQLite + Redis（可选）｜ Docker Compose + Nginx

## 快速开始

**方式一 · Docker Compose**

```bash
cp .env.example .env      # 至少修改 POSTGRES_PASSWORD 与 JWT_SECRET
docker compose -f infra/docker-compose.yml --env-file .env up -d --build
# 打开 http://localhost
```

**方式二 · 本地开发**

```bash
cd api && pip install -r requirements.txt && uvicorn app.main:app --port 8000
cd web && npm install && npm run dev        # http://localhost:3000
```

**验证**：`powershell -ExecutionPolicy Bypass -File scripts/smoke.ps1` → `共 41 项检查：PASS 41 / FAIL 0`

## 数据来源与降级

- 美股默认 yfinance 公开接口，A 股默认 AKShare；付费源（Tushare / Finnhub 等）仅可通过 `.env` 自行接入，代码中**不含任何密钥**。
- 无合法免费源的指标一律使用公开价量代理，并在 `/api/v1/meta/status` 与设置页「数据状态」标注来源与延迟，绝不伪装成真实资金流。
- 接口不可用时降级为确定性合成序列（`source: "synthetic"`），仅用于离线联调。

## 已知限制

- 估值指标为价格反推代理，`marketCap` 恒为 `null`（不编造缺失数据）。
- 期权链为 Black-Scholes 模型价，不是可成交报价。
- 回测股票池为固定样本，Alpha 偏高、Beta 偏低，不证明策略有效性。
- 邮件验证码需要额外配置 SMTP 才启用。
